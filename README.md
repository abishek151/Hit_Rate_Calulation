# Vector-Based Borehole–Joint Hit-Rate Workflow

This repository contains the Python implementation of the vector-based
three-dimensional workflow developed for evaluating borehole–joint hit rate
in pre-excavation grouting.

## Associated manuscript

A vector-based analytical method for evaluating borehole–joint hit rate
in pre-excavation grouting of jointed rock masses

Authors: Abishek Shrestha, Kristin H. Holmøy, and Johan Funehag

## Method

The workflow represents tunnel alignment, borehole geometry, and joint-set
orientation in a common three-dimensional coordinate system. Hit rate is
calculated from the absolute dot product between the borehole direction
vector and the joint-plane normal vector.
